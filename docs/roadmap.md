# Roadmap

This framework grows alongside a public 90 session DevOps learning journey. Each playbook below gets added once the underlying skill is learned and proven.

## Complete

Server monitoring: disk checks, S3 backup, CloudWatch metrics, alarms, and email alerts.

## Planned

Infrastructure as code using Terraform.

Container deployment using Docker.

Microservices orchestration using Kubernetes.

Automated CI/CD pipelines.

Cloud cost optimization and FinOps automation.

Natural language to SQL database query assistant.

Multi cloud disaster recovery patterns.
